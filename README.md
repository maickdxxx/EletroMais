# EletroMais

Template reutilizável para eletricistas e empresas de serviços elétricos no catálogo do Coruja Host.

## Diferenciais do modelo

- identidade clara e tecnológica em azul + ciano;
- hero em duas colunas com card de atendimento rápido;
- projetos realizados com imagens editáveis;
- avaliações, diferenciais, processo, regiões e FAQ editáveis;
- páginas Início, Serviços, Quem somos, Contato e Blog;
- Blog carregado da API pública do Coruja Host;
- formulário real que prepara a solicitação no WhatsApp;
- logo, favicon, cores, contatos, SEO e textos editáveis;
- atualização em tempo real no preview do editor;
- Analytics oficial do Coruja Host sem projectId fixo;
- links reais de WhatsApp e telefone;
- SEO por página e schema Electrician;
- SPA preparada para Cloudflare Pages com `_redirects`.

## Build

```bash
npm install
npm run build
```

Saída: `dist`.
